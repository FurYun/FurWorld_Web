# 粘液科技入门

Slimefun 是一个让你无需安装客户端模组，就能体验科技玩法的插件。这里有自动化生产线、电力系统、魔法，甚至还有安卓机器人！

## 获取指南书

进入粘液科技服后，先拿一本指南书：
```
/sf guide
```
这本书包含所有物品和科技树，是你最重要的工具。

## 第一步：收集基础资源

### 黏液锭
这是所有机器的基础材料：
- 铁锭 × 4 + 黏液球 × 4 + 煤炭 × 1

### 电子管
用于电力设备：
- 铁锭 × 1 + 红石粉 × 1

### 平滑石头
用于机器外壳：
- 圆石在熔炉烧两次

## 第二步：建造你的第一台机器

### 基础自动熔炉
- 熔炉 × 1 + 红石 × 2 + 电子管 × 1 + 平滑石头 × 2
- 功能：自动熔炼附近掉落物

### 简易发电机
- 煤炭 × 3 + 电子管 × 1 + 红石 × 2
- 燃料：煤炭、木炭
- 输出：约 5 EU/t

### 能量调节器
- 将发电机的电力分配到机器
- 相邻放置即可连接

## 第三步：搭建电力系统

一个最简单的电力回路：
```
[发电机] → [能量调节器] → [机器]
```

## 解锁研究

```
/sf research    # 查看科技树
```

### 推荐解锁顺序
1. 基础电力 → 开启自动化
2. 矿物处理 → 双倍产出
3. 运输系统 → 方便移动物品
4. 自动农场 → 稳定食物来源

## 数据备份

你的科技进度会被保存，但建议定期备份：
```
/sf backups         # 查看备份
/sf backup create   # 手动备份
```

## 遇到问题？

- **机器没电**：检查燃料、能量调节器连接、电力消耗
- **研究点不够**：去挖矿/杀怪/合成物品赚取
- **机器被偷**：放在领地内，设置 `container false`
