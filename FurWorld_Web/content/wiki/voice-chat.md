# 语音聊天设置

FurWorld 内置语音聊天功能，支持 Java 版和基岩版玩家的实时语音交流。

## Java 版玩家

### 安装模组

去 Modrinth 或 CurseForge 下载 **Simple Voice Chat**：
- [Modrinth 页面](https://modrinth.com/mod/voicechat)
- 选择与你 Minecraft 版本匹配的版本

### 基本设置

1. 安装模组后启动游戏
2. 按 `V` 键打开语音设置
3. 确认显示 "Connected"
4. 调整音量和按键

### 默认按键

| 按键 | 功能 |
|------|------|
| `V` (长按) | 按住说话 |
| `V` (切换) | 切换开关 |
| `M` | 静音 |

## 基岩版玩家

基岩版原生支持语音：
1. 设置 → 音频 → 开启语音聊天
2. 确认麦克风权限已授予

## 跨平台互通

Java 版和基岩版玩家可以互相听到对方说话！

## 常见问题

**按 V 没反应？**
- 确认模组版本与 Minecraft 匹配
- 进服务器后等几秒再按

**听不到别人？**
- 检查主音量是否调到 0
- 检查是否被静音

**有延迟？**
- 佩戴耳机减少延迟
- 检查网络连接

---

> **建议**：佩戴耳机使用，既能避免回声问题，也能获得更好的沉浸感。
