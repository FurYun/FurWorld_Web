# 常见问题 (FAQ)

## 进不去服务器

**检查清单：**
1. 版本是否正确？休闲服 1.20.2，粘液服 1.21.1+
2. 地址和端口是否正确？
3. 网络是否正常？

**解决方法：**
- 重启客户端和路由器
- 尝试切换 DNS（如 8.8.8.8）
- 检查服务器是否在维护

## 皮肤不显示

**正版玩家：**
- 重启游戏，皮肤会自动同步

**离线/皮肤站：**
- 使用 `/skin set 你的ID` 手动同步
- 确认皮肤站账号正常

## 服务器卡顿

**客户端优化：**
- 降低渲染距离到 8-12 格
- 关闭阴影效果
- 关闭粒子效果
- 分配更多内存（-Xmx4G）

**服务器端：**
- 联系管理员用 `/clearlag` 清理实体
- 在领地内清理多余动物/怪物

## 被封禁了怎么办

**申诉流程：**
1. 联系管理员（QQ 群/Discord）
2. 说明情况，提供证据
3. 等待审核（通常 24 小时内）

**申诉模板：**
```
ID：你的名字
时间：被封时间
原因：管理员给的原因
解释：你的情况
```

## 怎么赚钱

- `/daily` 每日登录奖励
- `/rewards` 投票奖励
- 出售资源（矿石、食物）
- 完成任务

## 怎么传送

| 指令 | 用途 |
|------|------|
| `/home` | 回家 |
| `/spawn` | 出生点 |
| `/tpa <玩家>` | 传送到玩家 |
| `/warp <名称>` | 公共传送点 |

## 联系管理员

- QQ 群：见服务器公告
- GitHub：[FurWorld_Web Issues](https://github.com/FurYun/FurWorld_Web/issues)
