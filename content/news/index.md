# 服务器正式开放！

**2025-01-15**

经过一段时间的准备，FurWorld 正式和大家见面了！

## 开服信息

**休闲生存服**
- 地址：`smp.fur-island.asia:25565`
- 版本：Java 1.20.2 / Bedrock 1.21.40

**粘液科技服**
- 地址：`slime.fur-island.asia:25565`
- 版本：Java 1.21.1+ / Bedrock 1.21.40

**基岩版统一入口**
- 地址：`fur-island.asia:37864`
- 使用 `/server smp` 或 `/server slime` 切换

## 支持平台

- Java 版（离线/正版/皮肤站）
- 基岩版（iOS/Android/Xbox/Switch/PS4/PS5）

## 新手福利

- 新玩家自动获得起始资金
- 新手礼包（`/kit` 领取）
- 完整新手教程

## 服务器特色

- 温馨的福瑞亚文化社区
- 完善的领地保护系统
- 跨平台语音聊天
- 丰富的玩法内容
