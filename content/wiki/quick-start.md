# 快速入门指南

欢迎来到 FurWorld！这份指南会帮你快速上手，用最短的时间建立起属于你的小天地。

## 第一步：进入服务器

**Java 版玩家**
- 休闲生存：`smp.fur-island.asia:25565`
- 粘液科技：`slime.fur-island.asia:25565`

**基岩版玩家**
- 统一地址：`fur-island.asia:37864`
- 进入后用 `/server smp` 或 `/server slime` 切换

## 第二步：设置你的家

刚进服第一件事，就是设置一个家，这样随时都能回来：

```
/sethome home    # 设置一个叫 home 的家
/home home       # 随时传回家
```

## 第三步：看看你有多少钱

```
/money           # 查看余额
/kit             # 领取新手礼包
```

## 第四步：创建你的领地

领地可以保护你的建筑不被破坏：

```
/res create myhome    # 创建一个 50x50 的领地
/res info             # 查看当前领地信息
```

## 第五步：探索服务器

- 输入 `/cmi` 打开图形化菜单
- 输入 `/spawn` 回到出生点
- 输入 `/warp` 查看公共传送点

## 常用指令速查

| 指令 | 用途 |
|------|------|
| `/home` | 回家 |
| `/tpa <玩家>` | 传送到玩家身边 |
| `/tpaccept` | 接受传送请求 |
| `/back` | 返回上一个位置 |
| `/money pay <玩家> <金额>` | 转账 |
| `/baltop` | 富豪榜 |
| `/vote` | 投票获得奖励 |

## 遇到问题？

- 进不去服务器？检查版本和地址是否正确
- 皮肤不显示？用 `/skin set 你的ID` 同步
- 被破坏了？用 `/report <玩家> 原因` 举报

---

> 输入 `/cmi` 或 `/menu` 打开图形化菜单，大部分功能都能在里面找到！
