# 经济系统指南

FurWorld 的经济系统让你可以和其他玩家自由交易，经营自己的小店，或者简单地存钱买好东西。

## 基础指令

| 指令 | 用途 |
|------|------|
| `/money` | 查看余额 |
| `/money pay <玩家> <金额>` | 转账 |
| `/baltop` | 富豪榜 |
| `/sell` | 出售手中物品 |
| `/worth <物品>` | 查询价格 |

## 怎么赚钱

### 每日登录
每天上线就能领钱，连续登录还有额外奖励：
```
/daily        # 领取每日奖励
```

### 投票奖励
给服务器投票就能获得金币：
```
/rewards      # 查看投票奖励
```

### 出售资源
把挖到的矿石、种出的作物卖给服务器：
```
/worth 钻石   # 查看钻石价格
/sell         # 手持钻石出售
```

### 完成任务
```
/quests       # 查看可做的任务
```

## 怎么花钱

### 领地扩展
保护更多建筑需要金币：
```
/res expand   # 扩大领地范围
```

### 修复装备
```
/repair       # 修复手中装备的耐久
```

### 玩家交易
和其他玩家面对面交易：
```
/trade <玩家> # 打开安全交易界面
```

## 赚钱小技巧

1. **初期**：做任务 + 投票，快速积累启动资金
2. **中期**：建农场/矿场，稳定收入来源
3. **后期**：经营玩家商店，实现财富自由

## 注意事项

- 不要轻信陌生人"低价出售稀有物品"的广告
- 大额交易用 `/trade` 或当面交易
- 交易截图留证，出问题好申诉
